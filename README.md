# daily-report — 제뉴인 프로덕션 유튜브 일일 리포트

운영 채널 10개의 유튜브 공개 지표(구독자·조회수·최근 영상 성과)를 매일 수집해
전일·7일 전과 비교한 리포트를 만든다. 클라우드 루틴에서 무인 실행되도록 설계했다.

## 구조

| 파일 | 역할 |
|---|---|
| `channels.json` | 채널 목록. `enabled`로 수집 여부, `verified`로 ID 확인 여부 표시 |
| `collect.py` | YouTube Data API v3 호출 → `data/snapshots/YYYY-MM-DD.json` 저장, `data/history.csv` 추가 |
| `report.py` | 오늘 스냅샷을 1일·7일 전과 비교 → `reports/YYYY-MM-DD.md`, `.html` 생성 |
| `run.py` | 위 둘을 순서대로 실행 |
| `routine/daily-report-routine.md` | 클라우드 루틴에 등록할 프롬프트와 일정 |

## 실행

환경변수 `YOUTUBE_API_KEY`가 필요하다(클라우드 환경 "트렌드 브리핑"에 이미 설정됨).

```
python3 run.py            # 수집 + 리포트
python3 report.py 2026-09-28   # 특정 날짜 리포트만 다시 생성
```

Windows PowerShell에서 로컬 실행할 때:

```powershell
$env:YOUTUBE_API_KEY = "<키>"   # 세션 한정. 파일에 저장하지 말 것
python run.py
```

## 리포트 구성

1. 채널 요약: 구독자·총조회수와 Δ1일·Δ7일, 영상 수, 7일 업로드 수, 마지막 업로드
2. 지난 24시간 조회 증가 상위 10개 영상(전일 스냅샷이 있어야 계산됨)
3. 최근 7일 업로드 영상 중 조회수 상위 15개
4. 주의 신호: 7일 이상 업로드 없음, 구독자 감소, 채널 조회 실패

## API 쿼터

채널 1회 + 채널별 업로드 목록 1회 + 영상 통계 50개당 1회 → 하루 약 20 유닛.
일일 무료 한도 10,000 유닛의 0.2%.

## 주의

- 구독자 수는 API가 반올림한 값이다(예: 587,000). 소폭 변동은 Δ에 안 잡힐 수 있다.
- 비공개 지표(시청시간·수익·트래픽 소스)는 OAuth가 필요한 Analytics API 영역이라 다루지 않는다.
- API 키는 환경변수로만 읽고 파일·로그에 남기지 않는다.
